# Technology logos

The logos a card shows (`Prop.logos` in `src/lib/scenes/types.ts`; the Moosylvania loft's computers, Joe, 2026-10-01),
copied from the developer platform collection reviewed in `art/reviews/2026-10-01-developer-platform-logos.md`: the
compact brand-colour mark of each platform, [Simple Icons](https://simpleicons.org/) where it has one and the brand's own
asset for AWS, Heroku, Silverstripe CMS, Salesforce Marketing Cloud and Elasticsearch. Elasticsearch uses the colored product icon from
[Elastic’s official integrations repository](https://github.com/elastic/integrations/blob/main/packages/elasticsearch/img/logo_elasticsearch.svg).
Nothing is redrawn or recoloured. One file is
changed: `heroku.svg` has its `viewBox` drawn in round the mark (`290 290 140 140` of the original `0 0 720 720`), whose
canvas is mostly margin.

[logo.js](https://github.com/voodootikigod/logo.js), MIT. Vue artwork from [vuejs/art](https://github.com/vuejs/art),
CC BY-NC-SA 4.0. Every other mark is its owner's trademark, shown to name the technology.
